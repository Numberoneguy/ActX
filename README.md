# ActX
ActX is a eaglercraft-client based on a curseforge mod ACT made by ATE48. While it's a remake and not trying to port it there's more than just the curseforge mod.
# Installing the client.
1. Download the client (ActX_v1.6.2_WASM-GC*.html) and play it. Download the client from [Github Releases](https://github.com/Numberoneguy/ActX/releases)
2. Have fun with the client-side stuff from ATE48 and more features i added.

# Useful tips

- Customize your player tab to give it a beatiful look.
- Use the `/boom` command on someone to explode them with tnt.
- Change the gamerules since i added more and most of them are useful when making a parkour, pvp, etc.
- Turn off `Glint rendering`, and `Weather rendering` to avoid more lag when it comes
to low-end hardware like Chromebooks with bad CPUs (including GPU for the textures)
- Use the client-side commands like `/act head <user>` to give you someone's head using `SkullOwner:*`, and `UUID:*`
(most of them are modified so it can load up properly in eaglercraft.)
