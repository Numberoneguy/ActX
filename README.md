## ACT(X).

ACT(x) is a eaglercraft client based and a ported Forge Mod (Advanced Creative Tab by ATE47).
- `ACT` stands for Advanced Creative Tab 2
- `X` tells you that it's a eaglercraft client.<br>
It`s very easy to understand the name of the client. This is a personal project i really felt like to make, nothing else.

## What it contains and about.
**(1.8.8 u53)**
- focuses on porting mordern items, features for LAN, adding more support. 
- It contains more opti-fine settings into eaglercraft. (*Quality, Details, Animations, Others*)
- 26.2 Items that have been backported into 1.8.8.
- More singleplayer features/support, and WispCraft support.
- Use illegal characters in chat (paste § and it'll register without it being ignored but ofc it will kick you out if you try to send it.)
- More FNAW Skins (for now there is just one custom FNAW Skins added)<br>
**(1.12.2 u2)**
- focuses on porting simple forge mods, for instance, AppleSkin, ACT2, Mrcrayfish's gun mod (wasn't simple and took 4 days), Mutant Creatures Legacy (same reason as Mrcrayfish`s gun mod), and etc.
- ported more modssssss.
- this project has forge patches and more.
